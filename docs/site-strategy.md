# Emily pets 俄罗斯站定位与页面架构

日期：2026-10-27。状态：实施基线，搜索所有权为建议，尚无 GSC / Yandex 查询表现数据。

## 已确认与环境

用户确认 Emily pets 品牌，范围为猫砂及宠物垫料；俄语默认，独立站。
空 Git 仓库，无现有代码、依赖、环境文件及部署配置。Windows / PowerShell，Node 26.7.0，npm 11.19.0。
采用单语言 Next.js App Router，根路径俄语，不创建无内容的英文入口，不加 /ru 前缀。

## 三站边界

emilypets.com 已存在俄语页面，负责品牌、企业、制造能力、具体产品和通用批发词。
love-pets.asia 负责国际采购指南、选品、RFQ、样品评估、包装 brief。其本地参考项目也配置俄语，不能只靠语言区分新站。
俄罗斯站负责俄罗斯采购项目的俄文规格协同：以项目为单位整理猫砂/垫料品类、SKU、计量口径、包装版本、目的地和待确认项。它是营销入口与本地规格准备工具，不冒充已上线的订单管理系统。

核心受众：俄罗斯进口商、区域经销商及零售采购团队。主要动作：形成可下载的俄文采购项目说明，再通过用户确认的渠道联系销售。
首页 H1：«Подготовьте закупочный проект для российского рынка»。
不承诺俄罗斯库存、清关、当地实体、人民币/卢布结算、固定 MOQ、运费、交期、认证或俄罗斯合规。

## 首期页面与模块

1. `/`：定位 → 猫砂/宠物垫料两条项目路径 → 项目协同流程 → 原站资料入口 → 建立项目 CTA。
2. `/assortment`：猫砂与垫料任务说明，项目字段与待确认事项；具体产品链接原站。
3. `/project`：产品方向、SKU/包装、采购量与单位、目的地、待确认问题；在浏览器生成 JSON 文件。无姓名/电话/邮箱字段，无数据上传，无伪造成功送达。
4. `/about`：站点职责、三站关系的业务说明、资料与证据来源。不新造企业介绍。

首期不建博客、城市落地页、品牌 SKU 详情、伪法律政策、无效联系表单。
导航：Ассортимент / Как подготовить проект / О проекте；主要 CTA：Подготовить проект。

## 原创内容与技术规则

同一产品名允许自然出现；避免重复指的是同一查询意图和页面价值，而非禁用行业术语。
逐页核对 title、description、H1、正文、FAQ、图片、结构化数据和锚文本。原站事实引用不得变成新站工厂或本地库存承诺。
不复制原站文章、翻译包、工厂数字、证书图、销售联系方式或统计 ID。
不批量跨域 canonical。生产域名确定后使用自指 canonical；独立任务页不互设虚假 hreflang。
俄文经专业审阅前全站 noindex，空 sitemap；不 robots 禁爬，以便爬虫识别 noindex。
