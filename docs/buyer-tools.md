# 买家工具

2026-10-28：新增 /tools，以俄罗斯采购项目为使用场景，保持既有关键词归属和 noindex。

- 装箱计算：给定总包数、每箱包数、单包产品数量，计算向上取整箱数、尾箱包数、空位与总产品数量。公斤/升分别选择，不做密度换算；产品升数不视为运输CBM，不计算柜容或毛重。
- 单位价格：两种包装共同选择币种与单位，分别计算每单位价格；相对较高价计算差价比例。只比较输入价格，不推断质量、运费、税费或汇率。
- 采购清单：8个可勾选事项，UTF-8 BOM文本本地下载。状态只在页面内存中保存，不发给供应商。清单不是认证或合规结论。
- 产品页与全站页脚新增入口。无新增依赖、外部脚本、个人信息收集。
