# 四项互动功能

2026-10-28。用户明确要求全部加入：包装搭配台、30秒选品测验、互动材料图鉴、宠物互动助手。

/explore 集中前三项，全站右下角小猫提供手动展开、抚摸动作和功能入口；工具页与页脚加入入口。

包装台原品牌模式使用既有真实品牌素材；自有品牌模式使用代码绘制的抽象袋型和配色，明确标为不按比例的设计示意，不构成包装可生产、颜色准确或商业条件承诺。设计组合通过共享白名单验证后带入项目，原品牌模式忽略设计参数。

测验按猫/小动物先分组，再按材料偏好提供浏览方向。销售渠道仅改变需要比较的采购要点。不做健康、安全、适用性或最佳效果保证。

材料图鉴的颗粒/木屑为CSS示意，原包装图片和参数均复用原有资料；图形不冒充实拍。

宠物助手为本地交互，不调用AI或外部脚本，不主动弹出；支持收起与Escape，尊重减少动态效果设置。

所有选项只保存在当前页面内存。没有注册、服务器收集、第三方聊天或隐式持久化。
